# Лабораторна робота №6: Обробка відео за допомогою OpenC (C++)

**Опис проекту**
Програма для обробки відеопотоку з камери в реальному часі. Реалізована модульна архітектура (класи `CameraProvider`, `FrameProcessor`, `KeyProcessor`, `Display`).

**Вимоги до системи**
* **ОС**: Ubuntu або інший Linux-дистрибутив.
* **Залізо**: Наявність веб-камери.
* **Бібліотеки**: OpenCV 4.x.

**Швидкий запуск**
Для перевірки на чистій системі виконайте наступні команди:
 
**Встановлення залежностей**:
   ```bash
   chmod +x preinstall.sh
   ./preinstall.sh

**Збірка проекту**:
    ```bash
    chmod +x build.sh
    ./build.sh

**Запуск**:
    ```bash
    chmod +x run.sh
    ./run.sh

**Керування**:
1 - Звичайний режим.
2 - Інверсія кольорів.
3 - Gaussian Blur.
4 - Canny Edge (межі).
q або Esc — Вихід.
