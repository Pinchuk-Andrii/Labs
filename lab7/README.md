# Лабораторна робота №7: Computer Vision та багатопотоковість у C++

**Опис проекту**
Програма є розвитком попередньої лабораторної роботи та додає функціонал детекції облич у реальному часі за допомогою нейронної мережі ResNet-10 (SSD). Основна особливість використання багатопотоковості для забезпечення стабільно високого FPS (30–60 кадрів/сек), навіть під час виконання важких обчислень нейромережею.

**Вимоги до системи**
* **ОС**: Ubuntu або інший Linux-дистрибутив.
* **Залізо**: Наявність веб-камери.
* **Бібліотеки**: OpenCV 4.x (з модулем DNN).

q або Esc — Вихід.

**Архітектура проєкту** 
Програма реалізована з розділенням обов'язків між потоками для запобігання блокуванню інтерфейсу:
1. Main Thread (UI): Займається читанням кадру з камери, малюванням отриманих координат обличчя та відображенням відео.
2. FaceDetector (Worker Thread): Окремий клас, що запускає фоновий потік (`std::thread`). Він асинхронно виконує інференс нейромережі на копії кадру та оновлює координати облич.
3. Синхронізація: Для безпечного доступу до спільних даних (кадрів та координат) між потоками використовується `std::mutex`.
4. FrameProcessor: Використовується для накладання класичних фільтрів обробки зображень.

**Демонстрація багатопотоковості** 
Для підтвердження ефективності Рівня 2 у коді `FaceDetector.cpp` реалізована можливість додавання штучного навантаження (`std::this_thread::sleep_for`). Це дозволяє наочно продемонструвати, що відео залишається плавним, навіть коли рамка детекції оновлюється з великою затримкою.
